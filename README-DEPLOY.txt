GAME GOOD NOW — PREMIUM PS5 STOREFRONT UPDATE
============================================

DEPLOY
1. Upload the CONTENTS of this folder to the ROOT of your GitHub Pages repository.
2. Replace the existing index.html, styles.css and script.js.
3. Upload all image assets in this folder beside those files.
4. Keep the CNAME file exactly as supplied.
5. Do not upload the old nested GameGoodNow-Fixed-EUR.tar.gz archive.

WHAT CHANGED
- Rebuilt the storefront with a premium dark navy / cyan / blue-violet visual system.
- Reworked the mobile layout, product cards, featured sections, navigation and basket.
- Standardised all customer-facing copy in English.
- Limited the catalogue to PS5 games, a PlayStation 5 console and PS5-compatible accessories.
- Corrected the GTA V image to IMG_9087.webp, the supplied PS5 cover asset.
- GTA VI is shown as an upcoming listing only; it cannot be added to the basket.
- Removed non-PlayStation console/controller and unrelated accessory listings.
- Preserved the existing Revolut checkout URL.
- Added optional EmailJS templates for a store order-request email and a customer order-request acknowledgement.

IMPORTANT BEFORE LAUNCH
- Prices in the catalogue are existing proposed prices, not verified live supplier quotes.
- Confirm stock, exact edition, condition, region, compatibility, warranty and included accessories.
- The fixed Revolut payment link does NOT receive the basket total and does NOT send payment status back to this static website. Confirm the exact amount with the customer before payment.
- A static GitHub Pages site cannot securely verify payment. Do not automatically describe an order as paid or confirmed. Verify the transaction in Revolut before dispatch.
- Add your real legal business name, business address, registration details where applicable, delivery costs/times, returns/cancellation terms, privacy policy, warranty terms and tax information before taking orders. Do not invent these details or publish fake reviews/trust badges.
- Test the basket, mobile layout, all product images, EmailJS and Revolut flow before launch.

GAME GOOD NOW — ORDER EMAIL SETUP
=================================

IMPORTANT DISTINCTION
The current website uses a fixed Revolut payment link. It cannot pass the basket total to Revolut or receive a verified payment result. The website can send an order-request email, but it cannot safely send a "payment received" confirmation. Verify payment in Revolut first, then confirm the paid order manually. Automatic paid confirmations require a backend and a verified Revolut payment notification/webhook.

1. CREATE AN EMAILJS ACCOUNT
   Go to https://www.emailjs.com/ and connect the mailbox used by your store.

2. CREATE TWO EMAIL TEMPLATES

   TEMPLATE A — STORE ORDER REQUEST
   Set the recipient (To email) to your real store inbox.
   Set Reply-To to {{customer_email}}.
   Suggested subject: New order request {{order_number}} — {{order_total}}

   TEMPLATE B — CUSTOMER ACKNOWLEDGEMENT
   Set the recipient (To email) to {{customer_email}}.
   Suggested subject: We received your order request {{order_number}}
   The message must clearly say this is an order request only and payment/stock have not yet been verified. Do not say "paid", "payment received" or "order confirmed".

3. ADD THESE TEMPLATE VARIABLES TO BOTH TEMPLATES
   {{order_number}}
   {{customer_name}}
   {{customer_email}}
   {{customer_phone}}
   {{shipping_address}}
   {{order_items}}
   {{order_total}}
   {{order_status}}
   {{reply_to}}

4. ADD YOUR EMAILJS DETAILS
   Open script.js and replace:
   ADD_EMAILJS_PUBLIC_KEY
   ADD_EMAILJS_SERVICE_ID
   ADD_STORE_TEMPLATE_ID
   ADD_CUSTOMER_TEMPLATE_ID

   Use the Public Key from EmailJS Account, the Service ID from Email Services, and the two Template IDs from Email Templates.

5. TEST BEFORE GOING LIVE
   - Use your own email address and a test order.
   - Check that the store inbox receives the order request.
   - Check that the customer inbox receives the acknowledgement.
   - Check spam/junk folders.
   - Verify that the wording does not claim payment has been received.
   - Only after you verify a real Revolut transaction should you send a separate paid-order confirmation.

SECURITY / LIMITATIONS
EmailJS public browser keys are intended for client-side use; enable domain restrictions and rate limits in EmailJS. Never put a private API key or payment secret in script.js. Do not collect card details on this website.
